## Made for this project

| Item | How |
|---|---|
| Hall: floor flags, walls, piers, vault, ribs, windows | Original geometry, stone by stone (`pipeline/forge/build_forge.py`) |
| Fire bed in the fireplace: logs and coals | Original geometry (same script) |
| Anvil, quench trough, grindstone, bellows, bar stock, chain, coal | Original geometry (same script) |
| Fire flipbook (`forge_fire.webp`) | Own 2D fluid simulation, looped and cut into flame tones (`pipeline/forge/paint_fire.py`) |
| Light: occlusion and the furnace's light | Baked in Cycles into vertex colour |
| Smoke, light shafts, soot | Original shader code (`src/shaders-texpaint.js`) |

No AI-generated imagery, purchased asset or reference frame is used. The fireplace was downloaded by the owner, with their login.
