## Rules applied in the portfolio's text

1. Every team project names itself as one, with no teammates' names unless the owner wants them.
2. Nothing says "independently delivered" where git shows others committed.
3. Texas: no IDRT or Texas A&M logo or mark is used, and nothing suggests endorsement. TDIS is named only to say what the model plugs into.
4. Each project's "My contribution" section is **owner-only (`&review=1`) until the owner writes it**. The audit's draft is offered for confirmation, and is never shown to visitors as a claim.
