# Manga Ink Rendering Report

**Written for the owner.** See `captures/art/B-ink.png` and the board.

## What changed

Ink used to read the painted colour, so every brush dab became a hatching patch and the frame turned uniform grey. **It now reads the light on the surface,** so hatching follows planes. Each material has its own treatment:

| Surface | Treatment |
|---|---|
| Sky | Clean paper. Cloud contours and hatched undersides are drawn from the painted cloud card, plus a few long pen lines |
| Mountains | Fine lines following the slope, on shadow planes only; tops left as paper |
| Ground | Open paper, long level strokes that thicken in shadow, small grass flicks near the camera |
| Foliage | Black masses on the shadow side, leaf marks, white flecks |
| Architecture, cloth, wood | Two hatch families by plane, solid black in the deepest shadow, heavy contours, screentone beyond 170 m |
| Smoke and birds | Smoke as paper with a drawn edge; birds in solid ink |

## Faults that remain

- **Too few solid blacks.** The references depend on large black masses; this frame has few outdoors because the light is high and even.
- **Close-up hatching turns to grey moiré.** In the Forge test the lines are too fine for the screen. It reads as dither, not pen work. Line spacing must grow near the camera.
- **Mountain hatching is too regular.** It reads as a pattern; it needs variation in length and spacing.
- **Tents are hatched almost whole,** which flattens them.
- **Lines are mechanically even.** Thick-to-thin variation along a stroke is still limited.

**Honest grade:** it reads as a pen illustration and is a real step forward, but it isn't yet dense or confident enough to match the references.
