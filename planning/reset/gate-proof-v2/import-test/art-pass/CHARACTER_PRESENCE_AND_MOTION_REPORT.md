# Character Presence and Motion Report

**Written for the owner.**

## What changed

**The crowd is off.** The character system stays in the code and returns with `?stage=1`, but the main presentation no longer loads it.

| Before | Now, by default |
|---|---|
| 16 animated mannequins, 14 memory figures, a scripted horse | Two still figures at one fire, one watchman on the west tower, one rider crossing the far ridge |
| Horses walking the paddock | Two paddock horses (one grazing, one turning slowly), plus the 12 standing horses on the horse lines, which I didn't remove |
| 130k triangles of figures | 1,370 triangles for all horses and the rider, plus a few simple figures |

These are generic neutral figures. No character design, lore or protagonist was added, and no Berserk character or image is used.

## Motion left in the scene

Banners and horses step on twos. Smoke rises, sparks and fireflies move, and birds circle. Crows on the lane lift as the camera nears and settle as it retreats.
